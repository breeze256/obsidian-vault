## 概念
$$
z = a + b\mathrm{i} \quad \text{or} \quad z = a + \mathrm{i}b \quad (a, b \in \mathbb{R}).
$$
- **虚数单位**: $\mathrm{i}$ , 满足 $\mathrm{i}^2 = -1$.
- **复数集**: 全体复数集合, 记作 $\mathbb{C}$, 有 $\mathbb{C} \supsetneqq \mathbb{R}$.
- **实部**: $\Re(z) = a$.
- **虚部**: $\Im(z) = b$.

- **虚数**: 当 $b \neq 0$ 时, $z$ 称为虚数.
- **纯虚数**: 当 $a = 0$ 且 $b \neq 0$ 时, $z$ 称为纯虚数.

当且仅当 $b = 0$ 时, $(z = a) \in \mathbb{R}$;
当且仅当 $a = b = 0$ 时, $z = 0$;

## 复数的向量表示 复平面
$$
z = a + \mathrm{i}b \iff z(a, b) \iff \overrightarrow{Oz} = (a, b)
$$

- **复平面**: 用直角坐标系表示复数的平面.
	- $Ox$ 称为实轴, $Oy$ 称为虚轴.
	- 实轴上所有点表示实数, 虚轴上除原点外所有点表示虚数.

- **共轭复数**: 实部相等, 虚部互为相反数的两个复数互称共轭复数.
	- $z= a + \mathrm{i}b$ 的共轭复数用 $\bar{z} = a - \mathrm{i}b$ 表示.
	- $\forall \ z \in \mathbb{R},\ \bar{z} = z$.

- **复数的模**: 即向量 $\overrightarrow{Oz}$ 的长度, 记为 $\lvert z \rvert$ 或 $r$. 有 $\lvert z \rvert = r = \sqrt{a^2 + b^2} \geq 0$.

显然, $\lvert \Re(z) \rvert \leq \lvert z \rvert \leq \lvert \Re(z) \rvert + \lvert \Im(z) \rvert$, $\lvert \Im(z) \rvert \leq \lvert z \rvert \leq \lvert \Re(z) \rvert + \lvert \Im(z) \rvert$.


## 复数的运算

$$
\text{Let} \quad z_1 = a + \mathrm{i}b,\ z_2 = c + \mathrm{i}d
$$
### 运算

- **加法**: $z_1 + z_2 = (a + c) + \mathrm{i}(b + d)$.
- **减法**: $z_1 - z_2 = z_1 + (-z_2) = (a-c) + \mathrm{i}(b - d)$. 
- **乘法**: $z_1 \cdot z_2 = ac + \mathrm{i}bc + \mathrm{i}ad + \mathrm{i}^2 bd = (ac - bd) + \mathrm{i}(bc + ad)$.
	- $\lvert z \rvert^2 = a^2 + b^2 =(a + \mathrm{i}b)\cdot(a - \mathrm{i}b) = z \cdot \bar{z}$.
- **除法**: $\dfrac{z_1}{z_2} = \dfrac{a + \mathrm{i}b}{c + \mathrm{i}d} = \dfrac{(a + \mathrm{i}b)(c - \mathrm{i}d)}{(c + \mathrm{i}d)(c - \mathrm{i}d)} = \dfrac{ac + bd}{c^2 + d^2} + \mathrm{i}\dfrac{bc - ad}{c^2 + d^2}$.

### 运算律

- **交换律**: $z_1 + z_2 = z_2 + z_1$, $z_1z_2 = z_2z_1$.
- **结合律**: $(z_1 + z_2) + z_3 = z_1 + (z_2 + z_3)$.
- **分配律**: $z_1(z_2 + z_3) = z_1z_2 + z_1z_3$.

### 常用性质
$z = a + \mathrm{i}b$, $w = c + \mathrm{i}d$,

- $\Re(z) = \dfrac{1}{2}(z + \bar{z})$, $\Im(z) = \dfrac{1}{2\mathrm{i}}(z - \bar{z})$.
	-  Proof: $$\begin{gather} \dfrac{1}{2}(z + \bar{z}) = \dfrac{1}{2}(a + \mathrm{i}b + a - \mathrm{i}b) = a = \Re(z) \\ \dfrac{1}{2\mathrm{i}}(z - \bar{z}) = \dfrac{1}{2\mathrm{i}}(a + \mathrm{i}b - a + \mathrm{i}b) = b = \Im(z). \end{gather}$$
- $\overline{(z + z)} = \bar{z} + \bar{w}, \overline{zw} = \bar{z}\bar{w}$.
- $\overline{\left(\dfrac{z}{w}\right)} = \dfrac{\bar{z}}{\bar{w}} \ (w \neq 0)$.
- $\lvert zw \rvert = \lvert z \rvert\lvert w \rvert$, $\left| \dfrac{z}{w} \right| = \dfrac{\lvert z \rvert}{\lvert w \rvert} \ (w \neq 0)$.
	- Proof: $$\begin{align}\lvert zw\rvert &= \lvert (ac-bd) + \mathrm{i}(bc+ad)\rvert \\ &= \sqrt{(ac-bd)^2 + (bc + ad)^2} \\ &= \sqrt{a^2 + b^2}\sqrt{c^2+d^2} \\ &= \lvert z \rvert \lvert w \rvert, \\ \left| \dfrac{z}{w} \right| &= \left| \dfrac{a + \mathrm{i}b}{c + \mathrm{i}d} \\ \right| = \left| \dfrac{ac + bd}{c^2 + d^2} + \mathrm{i}\dfrac{bc - ad}{c^2 + d^2} \right| \\ &= \sqrt{\left(\dfrac{ac + bd}{c^2 + d^2}\right)^2 + \left(\dfrac{bc - ad}{c^2 + d^2}\right)^2} \\ &= \sqrt{\dfrac{a^2c^2 + b^2d^2 + b^2c^2 + a^2d^2}{(c^2 + d^2)^2}} \\ &= \dfrac{\sqrt{a^2 + b^2}}{\sqrt{c^2 + d^2}} = \dfrac{\lvert z \rvert}{\lvert w \rvert}. \end{align}$$

## 复数的三角表示 复数的方根

$\mathbb{C}$ 上不为 $0$ 的点 $z = x + \mathrm{i}y$ 有极坐标 $z(r, \theta)$ , 其中 $x = r\cos \theta$, $y = r \sin \theta$. 
- **幅角**: 称正实轴与从原点 $O$ 到  $z$的射线的夹角 $\theta$ 为幅角, 记为 $\theta = \mathrm{Arg} \ z$. $z$ 的幅角不唯一, 这些值相差 $2\pi$ 整数倍.
- **幅角的主值**: **通常**把满足条件 $-\pi < \theta_0 \leq \pi$ 的幅角 $\theta_0$ 称为 $\mathrm{Arg} \ z$ 的主值. 记为 $\theta_0 = \arg z = \arctan \dfrac{y}{x} \in [-\pi, \pi)$.  有 $\theta = \mathrm{Arg} \ z = \{\theta_0 + 2k\pi : k \in \mathbb{Z}\}$. (不连续点可以自己规定, 更普遍地, $\theta_0 \ \in [-\gamma, 2\pi - \gamma), \ \gamma \in \mathbb{R}$).
	- 给定 $r \in \mathbb{R}$, 对于 $z \in \mathbb{C} \neq 0$, $\dfrac{z}{\lvert z \rvert} = \alpha + \mathrm{i}\beta$, $\alpha^2 + \beta^2 = 1$. 存在唯一的 $\theta \in [-\gamma, 2\pi - \gamma)$, 使得 $\alpha = \cos \theta, \beta = \sin \theta$.
- 复数的三角表示式以及指数形式: $z = r(\cos \theta + \mathrm{i}\sin \theta) = r\mathrm{e}^{\mathrm{i}\theta}$. (欧拉公式: $\mathrm{e}^{\mathrm{i}\theta} = \cos \theta + \mathrm{i} \sin \theta$).

### 几何意义

#### 复数乘法

在 $\mathbb{C}$ 中, $1 =  \begin{pmatrix}1 \\ 0 \end{pmatrix}$, $\mathrm{i} =  \begin{pmatrix}0 \\ 1 \end{pmatrix}$. 设 $z = x + \mathrm{i}y, w = \alpha + \mathrm{i}\beta = \begin{pmatrix}\alpha \\ \beta \end{pmatrix}$, 考虑 $z$ 为映射 $T_z: \mathbb{C} \mapsto \mathbb{C} \quad w \mapsto z\cdot w$, 则
$$
T_{z}(w) = T_z\begin{pmatrix}\alpha \\ \beta \end{pmatrix} = \begin{pmatrix}x\alpha - y\beta \\ x\beta + y\alpha \end{pmatrix} = \begin{pmatrix}x & -y \\ y & x \end{pmatrix}\begin{pmatrix}\alpha \\ \beta \end{pmatrix} 
$$

设 $\lvert z\rvert = r, \arg z = \theta$, 则 
$$
T_z = \begin{pmatrix}x & -y \\ y & x \end{pmatrix}  = r\begin{pmatrix}\cos \theta & -\sin\theta \\ \sin \theta & \cos \theta \end{pmatrix} \ (旋转 \ \theta \ 角并伸缩\ r \ 个单位)
$$

**几何意义**: 两个复数相乘, 积的模等于这两个复数的模的积, 积的幅角等于这两个幅角的和.
