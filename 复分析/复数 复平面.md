## 复数

### 概念
$$
z = a + b\mathrm{i} \quad \text{or} \quad z = a + \mathrm{i}b \quad (a, b \in \mathbb{R}).
$$
- **虚数单位**: $\mathrm{i}$ , 满足 $\mathrm{i}^2 = -1$.
- **复数集**: 全体复数集合, 记作 $\mathbb{C}$, 有 $\mathbb{C} \supsetneqq \mathbb{R}$.
- **实部**: $\Re(z) = a$.
- **虚部**: $\Im(z) = b$.

- **虚数**: 当 $b \neq 0$ 时, $z$ 称为虚数.
- **纯虚数**: 当 $a = 0$ 且 $b \neq 0$ 时, $z$ 称为纯虚数.

当且仅当 $b = 0$ 时, $(z = a) \in \mathbb{R}$;
当且仅当 $a = b = 0$ 时, $z = 0$;

### 复数的向量表示 复平面
$$
z = a + \mathrm{i}b \iff z(a, b) \iff \overrightarrow{Oz} = (a, b)
$$

- **复平面**: 用直角坐标系表示复数的平面.
	- $Ox$ 称为实轴, $Oy$ 称为虚轴.
	- 实轴上所有点表示实数, 虚轴上除原点外所有点表示虚数.

- **共轭复数**: 实部相等, 虚部互为相反数的两个复数互称共轭复数.
	- $z= a + \mathrm{i}b$ 的共轭复数用 $\bar{z} = a - \mathrm{i}b$ 表示.
	- $\forall \ z \in \mathbb{R},\ \bar{z} = z$.

- **复数的模**: 即向量 $\overrightarrow{Oz}$ 的长度, 记为 $\lvert z \rvert$ 或 $r$. 有 $\lvert z \rvert = r = \sqrt{a^2 + b^2} \geq 0$.

显然, $\lvert \Re(z) \rvert \leq \lvert z \rvert \leq \lvert \Re(z) \rvert + \lvert \Im(z) \rvert$, $\lvert \Im(z) \rvert \leq \lvert z \rvert \leq \lvert \Re(z) \rvert + \lvert \Im(z) \rvert$.


### 复数的运算

$$
\text{Let} \quad z_1 = a + \mathrm{i}b,\ z_2 = c + \mathrm{i}d
$$
#### 运算

- **加法**: $z_1 + z_2 = (a + c) + \mathrm{i}(b + d)$.
- **减法**: $z_1 - z_2 = z_1 + (-z_2) = (a-c) + \mathrm{i}(b - d)$. 
- **乘法**: $z_1 \cdot z_2 = ac + \mathrm{i}bc + \mathrm{i}ad + \mathrm{i}^2 bd = (ac - bd) + \mathrm{i}(bc + ad)$.
	- $\lvert z \rvert^2 = a^2 + b^2 =(a + \mathrm{i}b)\cdot(a - \mathrm{i}b) = z \cdot \bar{z}$.
- **除法**: $\dfrac{z_1}{z_2} = \dfrac{a + \mathrm{i}b}{c + \mathrm{i}d} = \dfrac{(a + \mathrm{i}b)(c - \mathrm{i}d)}{(c + \mathrm{i}d)(c - \mathrm{i}d)} = \dfrac{ac + bd}{c^2 + d^2} + \mathrm{i}\dfrac{bc - ad}{c^2 + d^2}$.

#### 运算律

- **交换律**: $z_1 + z_2 = z_2 + z_1$, $z_1z_2 = z_2z_1$.
- **结合律**: $(z_1 + z_2) + z_3 = z_1 + (z_2 + z_3)$.
- **分配律**: $z_1(z_2 + z_3) = z_1z_2 + z_1z_3$.

#### 常用性质
$z = a + \mathrm{i}b$, $w = c + \mathrm{i}d$,

- $\Re(z) = \dfrac{1}{2}(z + \bar{z})$, $\Im(z) = \dfrac{1}{2\mathrm{i}}(z - \bar{z})$.
	-  Proof: $$\begin{gather} \dfrac{1}{2}(z + \bar{z}) = \dfrac{1}{2}(a + \mathrm{i}b + a - \mathrm{i}b) = a = \Re(z) \\ \dfrac{1}{2\mathrm{i}}(z - \bar{z}) = \dfrac{1}{2\mathrm{i}}(a + \mathrm{i}b - a + \mathrm{i}b) = b = \Im(z). \end{gather}$$
- $\overline{(z + z)} = \bar{z} + \bar{w}, \overline{zw} = \bar{z}\bar{w}$.
- $\overline{\left(\dfrac{z}{w}\right)} = \dfrac{\bar{z}}{\bar{w}} \ (w \neq 0)$.
- $\lvert zw \rvert = \lvert z \rvert\lvert w \rvert$, $\left| \dfrac{z}{w} \right| = \dfrac{\lvert z \rvert}{\lvert w \rvert} \ (w \neq 0)$.
	- Proof: $$\begin{align}\lvert zw\rvert &= \lvert (ac-bd) + \mathrm{i}(bc+ad)\rvert \\ &= \sqrt{(ac-bd)^2 + (bc + ad)^2} \\ &= \sqrt{a^2 + b^2}\sqrt{c^2+d^2} \\ &= \lvert z \rvert \lvert w \rvert, \\ \left| \dfrac{z}{w} \right| &= \left| \dfrac{a + \mathrm{i}b}{c + \mathrm{i}d} \\ \right| \\ &= \left| \dfrac{ac + bd}{c^2 + d^2} + \mathrm{i}\dfrac{bc - ad}{c^2 + d^2} \right| \end{align}$$
